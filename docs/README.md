## 문서 관리 규칙

- 기능 변경 시 현황과 개발일지를 함께 갱신합니다.
- 완료·예정·미검증을 구분하고 실제 가격, 추정 가격, 예시 차트를 혼동하지 않습니다.
- 검증일과 데이터 집계 시점을 남깁니다. 출시 기간 조건 때문에 공개 수량은 시간이 지나면 달라집니다.
- API 키·비밀번호·실제 `.env` 내용은 문서나 Git에 저장하지 않습니다.
- 제조사 사양 출처와 공개 데이터 라이선스 고지는 유지합니다.
