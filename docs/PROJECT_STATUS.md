# 프로젝트 현황

현재 구현 상태를 정리합니다. 제품 수량은 마지막 로컬 집계이며 출시 기간·DB 복원 여부에 따라 달라집니다. 최신 검증 범위는 [검증 안내](TESTING.md)를 확인합니다.

## 목표

PC 견적·부품 추천을 유지하면서 국내 IT 기기의 목록 탐색, 검색, 사양 비교, 구매 링크와 향후 대여 기능을 제공하는 졸업프로젝트입니다. 사용자가 검색하기 전부터 사전 등록된 제품을 목록으로 볼 수 있도록 구성합니다.

## 구현 상태

| 구분 | 현재 상태 |
| --- | --- |
| IT 기기 목록 `/devices` | 스마트폰·노트북·태블릿·스마트워치, 최근 5년 및 국내 근거 조건 |
| PC 부품 `/parts` | CPU·메인보드·RAM·GPU 등 부품과 주변기기 탐색, 이전 부품 URL 이동 처리 |
| 기기 비교 `/devices/compare` | 동일 품목 최대 3개, 브랜드 필터, 차이점 표시, 출처 링크 |
| 기기 사양 | 제조사 자료 사전 등록, 한국어 항목명·사양 그룹, 미확인 값 표시 |
| 공식 판매처 | 확인된 제품은 구매 페이지, 미확인 제품은 공식몰 홈으로 연결하며 버튼 아래에 안내 |
| 가격 후보 | 비공식 `danawa-cli` 검색 결과와 판매 페이지 이동 |
| 쿠팡 | API 미연결 |
| 네이버 쇼핑 | 검색 이동 링크 제공. 가격 검색 API 연결 완료 상태가 아님 |
| 가격 변동 `/devices/prices` | 화면 및 예시 차트 구현. 실제 가격 시계열 미연결 |
| PC 견적 | 실제 부품 DB 기반 생성·교체·기본 호환성 확인. 가격/FPS 추정치 한계 있음 |
| 회원·저장·게시판 | Supabase 설정 필요. 현재 미설정 환경에서 사용 불가 |
| 대여 | 재고·예약·반납·결제 미구현 |

마지막 로컬 집계는 스마트폰 18, 태블릿 14, 스마트워치 5, 노트북 22개입니다. 노트북 브랜드는 ASUS·Apple·LG·Samsung입니다. 스마트폰 수에는 Git에 없는 로컬 TechSpecs 국내 모델 3개가 포함되므로 새 컴퓨터에서 수량이 다를 수 있습니다. 전체 국내 시장을 수집한 수량은 아닙니다.

PC 원본 데이터는 수집 당시 47,436개/23종이며 글로벌 자료입니다. IT 화면에서 쓰는 공식 노트북 목록과 PC 원본에 있는 노트북 118개를 중복 합산하지 않습니다.

## 다음 작업

1. 새 컴퓨터에서 코드·환경·DB를 복원하고 검색과 비교를 확인합니다.
2. 국내 판매 SKU 및 제조사별 제품을 확대하고 LG 사진·RAM/저장 옵션 등 누락을 검수합니다.
3. 가격 후보의 용량·국내/해외·통신 조건을 더 정확히 매칭하고 가격 이력을 저장합니다.
4. Supabase 회원·저장 흐름을 검증한 뒤 대여 재고·예약·반납을 설계합니다.

TechSpecs 추가 유료 수집은 중단 상태입니다. 기본 셋업이나 기능 확인을 위해 유료 수집을 실행하지 않습니다. 홈 화면은 기존 요청에 따라 유지됐으며, 홈의 과거 소개 문구와 현재 데이터 상태가 다를 수 있습니다.

## 공식 판매처 및 개발 규칙

제조사 4곳(삼성·Apple·LG·ASUS)과 모바일 품목의 통신사 3곳(SKT·KT·LG U+)을 연결합니다. 현재 제품별 확인 주소는 5개이며 그 외에는 공식몰 홈과 안내 문구를 제공합니다. 실시간 재고 연동이 아니며 판매처의 세대 교체·품절 시 재검수가 필요합니다. [판매처 링크 관리](OFFICIAL_STORES.md)를 참고하세요.

Ponytail 규칙은 루트 AGENTS.md와 라이선스 파일로 적용했습니다. 별도 런타임·자동 훅은 설치하지 않았습니다.
