## 수정한 실제 오류

1. `PartSelector.vue`가 견적 결과 화면에 사용되지 않아 검색창을 열 수 없었다. 부품별 변경 버튼과 검색창을 연결했다.
2. 견적 생성 직후 상태 초기화가 로딩 표시를 꺼 버렸다. 초기화와 로딩 설정 순서를 고쳤다.
3. 부품 변경 후 호환성·권장 파워·사용 전력이 갱신되지 않았다. 서버 재검사와 변경 상태 저장을 추가했다.
4. 예전 부품에 대한 AI 리뷰/FPS가 남거나 늦은 응답이 새 상태를 덮어쓸 수 있었다. 분석 무효화와 요청 버전 검사를 추가했다.
5. 캐시된 원본 객체에 추천용 스펙/대안 참조가 누적될 수 있었다. 추천 시 사양을 복사하고 이전 대안을 제거한다.
6. 사무용 고예산의 내장 GPU를 모두 제외하는 조건과 일부 부품의 무효화된 fallback 때문에 실제 제품이 있어도 생성이 실패했다. 조건/실제 대체 선택을 수정했다.
7. CPU 쿨러 소켓·GPU 길이·쿨러 높이·보드 규격이 사용자 변경 후에도 검증되도록 보완했다. 내장 GPU 0W를 200W로 치환하지 않는다.
8. 가격 미확인 제품으로 변경했는데 부분 합계를 전체 금액처럼 볼 수 있었다. 부분 합계와 비교 제한을 안내한다.

AI 리뷰를 호출하지 않고 견적과 DB 연결을 확인할 수 있도록 마지막 단계에 ‘AI 리뷰 없이 견적만 보기’를 추가했다. AI 리뷰/AI 비교 자체의 외부 응답 품질과 요금은 이번에 검증하지 않았다.

## 검증 명령과 근거

```powershell
cd C:\pc-fit-main\back
npm test
node scripts/verifyCatalog.js
node scripts/verifyBuilds.js
node scripts/verifyApp.js
```

- 자동 회귀 테스트 **41/41 통과**: 기존 기기 25, PC 카탈로그 8, 견적/교체 흐름 8.
- 저장 DB 기반 견적 시나리오 **12/12 생성 및 기본 물리 호환 조건 통과**. 모든 BIOS 버전·간섭·PSU 케이블 조건 검증을 의미하지 않는다.
- **12개 중 6개는 추정 합계가 목표 예산을 넘는다.** 예: 80만 원 게이밍은 추정 101만 원, 150만 원 게이밍은 추정 153만 원. 화면에서 초과 금액을 표시한다. 예산 준수가 완료됐다는 뜻은 아니며 실판매가 연결 및 추천 예산 배분 개선이 남았다.
- 실행 서버 HTTP 점검 10개: 성공/입력 거절/로그인 요구/DB 미설정 상태가 예상과 일치.
- 프론트엔드 프로덕션 빌드 성공. 기존 Vuetify CSS/번들 크기 관련 경고는 남아 있다.
- 브라우저에서 실제 CPU 변경과 복원, 3기기 비교표와 차이점 필터를 조작해 확인했다.
