- danawa-cli 3.0.0을 백엔드에 설치하고 실제 SM-S921N 검색 성공을 확인했다.
- 제품 ID 기반 `/devices/products/:id/offers` 경로와 가격 화면의 조회 버튼, 상품명·판매처·가격·판매 조건 링크를 추가했다.
- 네이버 쇼핑 공식 shop.json 호출을 구현했다. `.env.example`에 입력된 인증값을 `.env`로 옮기고 예제 파일의 값을 안내용 문자열로 복원했다.
- 실제 네이버 호출은 HTTP 401, 제공자 오류 코드 024로 실패했다. 인증 정보 확인이 필요하다. 비밀값은 로그에 출력하지 않았다.
- 검색 결과의 중고·리퍼·액세서리 일부를 제외하며 검색 결과 가격순으로 표시한다. 용량 및 통신사 조건이 다른 결과가 포함되므로 동일 조건 최저가 확정 기능은 미완료다.
- 프론트 빌드 통과. 실행 중인 서버 재시작 및 새 화면 브라우저 검증은 아직 수행하지 않았다.
- 공식 스펙/사진 수집 확대, 네 품목 모두의 최근 4년 정책, 노트북 데이터 검수 수입, 디자인 색표/taste-skill 후속 작업은 남아 있다. 이번 기록은 전체 요구 완료를 뜻하지 않는다.

## 프로젝트 목표

학교 전공심화 졸업프로젝트. 기존 PC 견적·추천 프로젝트를 기반으로 실제 PC 부품 검색, 견적 구성 및 호환성 확인, IT 기기 스펙 비교를 제공한다. 향후 기기 대여 기능을 추가한다. 스마트폰 전용 사이트로 바꾸는 것이 아니라 PC 견적 기능과 기기 비교 기능을 함께 발전시킨다.

## 2026-11-07~10 — 현재까지의 작업 정리

이전 작업은 저장된 코드와 QA_REPORT.md, DATA_SOURCES.md를 기준으로 정리했다. 아래 검증 수치는 이전 기능 점검 결과이며 이후 변경의 검증 결과와 구분한다.

### 데이터 및 API

- TechSpecs 인증·검색·상세 수집 코드를 연결했다. 수집한 상세 정보를 로컬 SQLite DB에 저장한다. 공개 스마트폰은 국내 모델 Galaxy S24, S24+, S24 Ultra 3개다. 중국 모델 1개는 공개 목록에서 제외했다.
- 스마트폰·태블릿·스마트워치의 최근 4년 조건과 국내 스마트폰 확인 정책을 구현했다. 태블릿·스마트워치는 현재 실제 저장 데이터가 없다.
- 무료 BuildCores 원본 데이터를 수집해 PC 부품과 주변기기 23개 품목, 중복 제거 후 47,436개 제품을 별도 SQLite DB에 저장했다. 출처와 CC BY-NC-SA 4.0 라이선스를 보존했다.
- CPU, 메인보드, RAM, 그래픽카드, 저장장치, 파워, 케이스, 쿨러 등을 검색하고 상세 사양을 확인할 수 있다.
- 국내 실판매가·판매처·가격 이력 API는 연결되지 않았다. 네이버 쇼핑·다나와·PhoneArena 데이터 연동도 완료된 상태가 아니다.
- TechSpecs 추가 유료 호출은 사용자의 요청으로 중단했다. 비밀키와 로컬 제품 DB는 Git에 올리지 않는다.

### 구현 및 기능 점검

- 실제 카탈로그 검색, 제조사/품목 필터, 페이지 이동, 제품 상세 화면을 연결했다.
- 국내 스마트폰 2~3개 비교, 차이점만 보기, 공유 URL을 구현하고 실제 브라우저에서 확인했다.
- 견적 결과에서 부품 직접 검색·교체를 연결했다. 교체 후 합계, 전력, 권장 파워, 호환성을 다시 계산한다.
- 이전 부품의 AI 설명·FPS가 남는 문제와 오래된 비동기 응답이 새 결과를 덮는 문제를 수정했다.
- 가격이 없는 제품은 0원으로 표시하지 않고 가격 미확인·부분 합계를 안내한다.
- 견적 생성과 기본 호환성 검사를 실제 부품 데이터에 연결했다. 외부 AI 호출 없이 견적만 확인할 수 있는 흐름을 추가했다.
- 이전 검증: 자동 테스트 41개 통과, 견적 시나리오 12개 생성, 로컬 HTTP 상태 점검 및 프론트 빌드 통과. 다만 12개 견적 중 6개는 추정 합계가 예산을 초과했다.

### 미완료 사항과 오해를 정리한 내용

- **API 인증/일부 상세 수집 완료 ≠ 공급처 전체 제품을 검색하는 서비스 완성.** 현재 공개 검색은 저장된 DB를 읽는다. TechSpecs 전체 범위의 사용자 검색 → 상세 조회 → 저장·재사용 흐름은 미완료다.
- DB에 API 응답을 저장하는 방식 자체는 정상이나, 저장한 스마트폰 3개만 검색되는 상태는 원하는 최종 서비스가 아니다.
- PC 부품 원본은 글로벌 데이터다. 국내 정발·현재 판매 중·실판매가가 확인됐다는 뜻은 아니다.
- 견적 가격·FPS 등은 추정이며 실측/실시간 가격이라고 안내하면 안 된다.
- Supabase 미설정으로 회원·저장·커뮤니티 기능이 사용 불가다. 대여 재고·예약·반납 기능도 아직 없다.
- 변경은 로컬 작업 상태이며 GitHub 업로드 완료로 간주하지 않는다.

## 2026-11-07 — 프론트엔드 개편 시작

### 사용자 결정

DB 공급처 확장과 추가 수집은 나중에 다시 진행한다. **최종 지시: 홈 화면은 수정하지 않는다.** 기기 검색·상세·비교·가격 변동 화면을 우선 개선한다. 홈 화면에 사용하는 기존 헤더·푸터·테마도 유지한다.

### 이번 작업 범위

1. [노피](https://nofee.team/)의 탐색, 기기 비교, 가격 정보 배치와 화면 구성을 참고한다. PC-FIT의 기존 PC 견적 흐름을 유지하면서 독자적인 문구·브랜드·컴포넌트로 구현한다.
2. 홈을 제외한 카탈로그·비교·가격 화면에 별도 디자인과 내비게이션을 적용한다.
3. 가격 변동을 확인하는 화면을 준비하되 실제 가격 이력이 없는 상태를 명확히 표시한다. 임의 가격을 실제 시세처럼 만들지 않는다.
4. [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)을 읽고 기존 Vue 프로젝트에 맞춰 디자인을 다듬는다.
5. 빌드와 화면/핵심 동작을 확인하고 결과와 남은 작업을 이 문서에 추가한다.

현재 상태: 진행 중. taste-skill의 공개 SKILL.md를 읽었다. 원본 저장소 복제는 네트워크 제한 후 승인 요청이 취소되어 실행하지 않았다. 읽은 디자인 지침은 참고하되 패키지 설치·전용 검사 통과로 표기하지 않는다. 노피의 실제 비교/가격 화면은 브라우저로 확인했다. 가격 이력은 DB 작업 보류에 따라 미연결 상태와 명시적 예시 화면을 구분해 구현한다.

## 2026-11-07 — 홈 제외 UI 개편 결과

### 구현한 화면

- `/devices`: 밝은 배경, 품목 바로가기, 검색/제조사 필터, 제품 카드, 실제 사양 상세, 가격 이력 이동을 정리했다. CPU·RAM·메인보드 등 기존 PC 부품을 유지했다.
- `/devices/compare`: 품목 탭 → A/B/C 기기 선택 → 차이 요약 → 핵심/전체 사양 표의 흐름을 정리했다. 기존 2~3기기 비교·차이점 필터·공유 링크를 유지했다. 작은 화면에서는 비교표 내부만 가로 스크롤된다.
- `/devices/prices`: 제품 검색·선택, 선택한 제품의 사양/비교 화면 연결, 가격 이력 패널을 추가했다. 링크에 모델 ID와 품목을 유지한다.
- `PriceHistoryPanel.vue`: 30일·90일·1년 기간 선택, 최저/최근 가격과 변동 금액, 선 그래프, 날짜별 기록 표, 빈 이력 상태를 구현했다. 실제 이력은 아직 없으며 기본 화면에 미연결로 안내한다. **‘예시 차트 보기’를 눌렀을 때만 가상 상품 데이터를 표시하며 실제 제품 가격·견적·DB에 반영하지 않는다.**
- 기기 페이지에만 별도 헤더·푸터·Vuetify 밝은 테마를 적용했다. 홈·기존 견적 페이지에는 기존 테마와 컴포넌트가 유지된다. 새 의존성 설치, 유료 API 호출, DB 수집은 하지 않았다.

### 참고한 디자인과 적용 방식

- [노피 비교](https://nofee.team/compare): 품목 선택, 나란한 제품 선택 영역, 비교 조합 진입 흐름을 참고했다.
- [노피 가격](https://nofee.team/price): 제품을 선택해 가격과 기록 시점을 확인하는 정보 흐름을 참고했다. 해당 사이트의 판매가를 복사하거나 PC-FIT 실판매가로 사용하지 않았다.
- [taste-skill SKILL.md](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md): 동일한 좌우 여백, 제한된 색상, 제목 계층, 간결한 문구, hover/focus 응답, 모바일 실제 브라우저 확인 원칙을 참고했다. 기존 Vue/Vuetify 구조를 유지했다.
- 도구 원본 복제 승인 취소로 taste-skill은 설치하지 않았으며 전용 gate/checker도 실행하지 않았다. 화면 전체 높이의 홍보 섹션이나 WebGL 효과는 이번 사용자의 비교 서비스 화면 목적에 적용하지 않았다. **taste-skill 전체 자동 검사 통과를 의미하지 않는다.**

## 2026-11-10 — 제조사 DB 보강, 최근 5년 국내 기준, 탐색 분리

- 기존 4년 정책을 네 가지 품목 모두 5년으로 변경. 서울 날짜와 국내 정식 출시 근거를 함께 검사한다.
- 공식 Apple 페이지 수집기를 추가하고 CPU·저장 공간뿐 아니라 카메라·운영체제·배터리·연결 사양을 보강했다. 삼성·LG·ASUS 공식 자료 및 사양표도 검수했다.
- 사전 등록 자료를 로컬 SQLite에 저장한다. 방문자의 검색·비교는 TechSpecs를 호출하지 않는다. PC 부품 DB는 별도로 유지.
