## 실행·갱신·다른 컴퓨터에서 복원

Node.js 22.13 이상이 필요하다. API 키 없이 무료 PC DB를 복원할 수 있다.

```powershell
cd C:\pc-fit-main\back
npm install
npm run sync:parts
npm start
```

다른 터미널에서:

```powershell
cd C:\pc-fit-main\front
npm install
npm run serve
```

브라우저에서 `http://localhost:8080/devices`를 연다. 파일을 이미 받았다면 `npm run import:parts`로 네트워크 없이 재등록한다. 갱신은 자동 유료 API 호출 없이 `npm run sync:parts`를 명시 실행할 때만 이뤄진다.

- 실제 DB: `back/.local/parts-catalog.sqlite`.
- 원본·라이선스·다운로드 버전: `back/.local/buildcores/`.
- 수집 결과: `back/.local/parts-import-report.json`.
- HTTP/DB 검증 결과: `back/.local/catalog-verification.json`.
- 모두 Git에서 제외된다. 다른 컴퓨터에서는 수집 명령을 다시 실행하거나 SQLite 파일을 별도로 복사해야 한다. 원본/수정 데이터의 공개 배포 시 출처·동일 라이선스 조건을 지킨다.
- 배포 서버는 영속 디스크를 마운트하고 `PARTS_CATALOG_PATH`에 DB 파일 경로를 지정해야 한다. Git 코드를 올리는 것만으로 이 PC의 DB 파일이 전송되지 않는다.

## 기존 프로젝트 연결 범위

`/devices`에서 모든 품목의 목록·제조사 필터·제품명/모델 검색·페이지 이동·상세 조회를 제공한다. 기존 견적의 부품 선택창과 `/search/parts`, `/search/parts-db`도 실제 PC DB를 조회한다. Supabase 미설정 시 기존 견적·AI 어드바이저의 부품 조회가 같은 로컬 DB를 사용한다.

기존 견적 알고리즘은 예상 가격·성능 점수·FPS를 사용하는 코드가 남아 있다. 이를 실판매가/실측치로 주장하지 않도록 화면과 API에 추정값임을 표시했다. 새 카탈로그의 판매가는 `null`이며 ‘국내 가격 미확인’으로 표시한다. CPU/GPU 조합 평가 규모를 제한하기 위해 추천 알고리즘에서는 GPU 칩셋당 실제 대표 모델을 사용한다. 공랭 쿨러 소켓/높이 및 케이스 메인보드 규격/GPU 길이 조건을 추가했지만 모든 BIOS·간섭 조건이 검증된다는 뜻은 아니다.

## TechSpecs와 미연결 공급처

- TechSpecs: 기존 국내 Galaxy S24·S24+·S24 Ultra 3개 공개. W24 중국 모델 1개는 숨김. 모바일 최근 4년/국내 스마트폰 정발 근거 정책 유지.
- 계정 화면에서 Standard `$0.02/request`를 확인했고, 사용자가 **추가 유료 호출 없이 무료 데이터만 연결**을 선택했다. 이번 PC DB 작업에서는 TechSpecs 추가 호출을 하지 않았다.
- 태블릿·스마트워치: 비교 로직은 있으나 실제 저장 제품은 아직 0개다.
- 네이버: 현재 코드는 이미지 API/외부 쇼핑 검색 링크를 사용한다. 국내 쇼핑 가격 API는 아직 미연결이며 키도 미설정이다. 쇼핑 검색 링크를 가격 API 연결로 표현하면 안 된다.
- 다나와·PhoneArena: 계약/제공 피드/키가 없고 실제 연결되지 않았다.
- 대여 예약·재고·반납, 회원/견적 저장용 Supabase 설정은 이번 PC 부품 DB 연결과 별도 미완료다.

추가 데이터가 필요하면 먼저 무료 제조사 자료/사용 가능한 공개 데이터를 검토한다. TechSpecs 유료 수집은 새 비용 승인이 있기 전에는 재개하지 않는다.
