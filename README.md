# PC-FIT

PC 부품 견적·추천을 기반으로 국내 IT 기기 검색·사양 비교·구매 링크를 제공하는 졸업프로젝트입니다. 대여 서비스는 향후 개발 범위입니다.

- **처음 실행:** [학교 및 새 컴퓨터 셋업](docs/SCHOOL_SETUP.md)
- **전체 문서:** [문서 목차](docs/README.md)
- **현재 구현 상태와 다음 작업:** [프로젝트 현황](docs/PROJECT_STATUS.md)
- **작업 기록:** [개발일지](docs/DEVELOPMENT_LOG.md)

프론트엔드는 Vue 3/Vuetify, 백엔드는 Node.js/Express입니다. 개발 환경에서는 SQLite 제품 DB를 사용하며 회원·게시판 기능에는 별도 Supabase 설정이 필요합니다.

실행 주소는 프론트엔드 `http://localhost:8080`, 백엔드 `http://localhost:3000`입니다. 백엔드와 프론트엔드를 각각 실행해야 합니다. 설치와 데이터 복원 명령은 셋업 문서를 따릅니다.

## 데이터와 기능 범위

스마트폰·노트북·태블릿·스마트워치는 국내 출시 근거와 최근 5년 조건을 적용합니다. PC 부품은 별도 화면에서 탐색합니다. 국내 전체 제품 DB, 실제 가격 이력, 대여·결제는 아직 완성되지 않았습니다. 가격 후보와 견적 추정 가격을 구분합니다.

API 비밀값과 `back/.local/` 데이터는 Git에 포함되지 않습니다. 다른 컴퓨터로 이동할 때 코드 외에 환경설정 및 DB 복원 여부도 확인해야 합니다.
